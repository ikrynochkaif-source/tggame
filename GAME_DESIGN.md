# AI-Creator Game Design

## Core fantasy

The player runs a tiny AI creator studio inside Telegram. Every session is a quick decision: ship fast, ship tasteful, or automate the work and hope the agents behave.

## Loop

1. Read the daily mission.
2. Pick a strategy.
3. Launch the project.
4. Receive a funny event and resource changes.
5. Hire agents, recover energy, climb the leaderboard.

## Resources

- Money: buys agents and future upgrades.
- Hype: increases viral score and leaderboard score.
- Reputation: long-term trust and quality score.
- Energy: limits repeated actions.
- XP: levels the player and restores energy on level up.

## Tone

Modern Ukrainian tech humor: AI agents, prompt culture, vibe coding, creator economy, overconfident models, Telegram funnels, clients without technical briefs, and “premium” design requests.

## MVP scope

This version is intentionally local-first and dependency-free. It proves the core loop and tone before backend work starts.
